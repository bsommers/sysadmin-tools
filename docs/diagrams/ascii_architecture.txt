(c) sys-io-guard PER-DISK FLOCK ARCHITECTURE
------------------------------------------------------------------------------------------------

  Caller A (cargo build on /datanapps/repo)        Caller B (competing build on /datanapps/app)
                 |                                                |
                 v                                                v
  +------------------------------------------------------------------------------------------+
  |  1. Pure Kernel Disk Resolution (NO lsblk / df subprocesses)                             |
  |     Target path -> /proc/mounts (longest mount prefix) -> device node                    |
  |     If dm-* (LVM/LUKS): walk /sys/block/dm-*/slaves -> underlying physical disk key      |
  +-----------------------------+----------------------------------+-------------------------+
                                |                                  |
                                v                                  v
  +------------------------------------------------------------------------------------------+
  |  2. Lock Acquisition in tmpfs ($XDG_RUNTIME_DIR/sys-io-guard or /tmp)                    |
  |     Lockfile: <disk_key>.lock     Metadata: <disk_key>.lock.meta (holder PID/cmd/ts)     |
  |                                                                                          |
  |     Caller A: fcntl.flock(LOCK_EX | LOCK_NB) -> ACQUIRED                                 |
  |               Write .meta JSON -> Set CARGO_BUILD_JOBS cap -> os.nice(+N)                |
  |               Direct subprocess.run(cmd, shell=False) -> Release lock on exit            |
  |                                                                                          |
  |     Caller B: fcntl.flock(LOCK_EX | LOCK_NB) -> EWOULDBLOCK                              |
  |               Read .meta JSON (report holder PID/cmd) -> Poll until --timeout            |
  |               If timeout expires -> stderr diagnostic -> EXIT 4 (Lock Busy/Timeout)      |
  +------------------------------------------------------------------------------------------+
