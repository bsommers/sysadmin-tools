Quick Install (Root NVMe Copy)

Clones the repository, runs the full local verification suite, and copies all 7 standalone binaries into ~/.local/bin. 

git clone https://github.com/bsommers/sysadmin-tools.git && cd sysadmin-tools && ./scripts/verify.sh && ./scripts/install.sh

Zero third-party packages. No symlinks to secondary disks, so diagnostics survive hung secondary mounts.

sys-investigate

Live Diagnostics

Diagnoses CPU/load spikes, storage I/O stalls, PSI pressure, NVMe thermals, GPU/cgroup contention, and per-PID trees directly from /proc and /sys — plus offline JSONL trend diffing.

Key flags:
--interval SEC --watch [N] --progress-check --no-statvfs --diagnose-pid PID --append-log PATH --diff-log PATH --diff-baseline PATH --diff-window N --exit-on-issue
Exit codes: 0 healthy/report · 1 input/error · 3 issue/degraded trend (with --exit-on-issue) 
sys-investigate --interval 2 --progress-check --no-statvfs

sys-io-guard

I/O & Storage

Serializes heavy builds and tests per backing physical disk via advisory flock on tmpfs/root, capping CARGO_BUILD_JOBS and child CPU niceness to prevent storage storms.

Key flags:
--path DIR --lock-key NAME --timeout SEC --cargo-jobs N --nice N --status --dry-run --json
Exit codes: child exit code (0 ok) · 1 error · 2 usage · 4 lock busy/timeout · 128+sig signal 
sys-io-guard --timeout 300 --cargo-jobs 4 --nice 10 -- cargo test

sys-mem-watch

Live Diagnostics

Measures per-process RSS/swap growth rates, direct vs kswapd page reclaim, memory PSI stalls, and OOM-kill risk directly from /proc/meminfo, /proc/vmstat, and /proc/<pid>/*.

Key flags:
--interval SEC --top N --watch [N] --append-log PATH --json --markdown --exit-on-issue
Exit codes: 0 healthy/report · 1 input/error · 3 non-healthy verdict (with --exit-on-issue) 
sys-mem-watch --interval 2 --top 10 --exit-on-issue

sys-disk-hogs

I/O & Storage

Iterative os.scandir() workspace and cache analyzer (zero du/find subprocesses) that deduplicates hardlinks, isolates reclaimable build caches from .git, and skips hung FUSE/network statvfs().

Key flags:
--top N --depth N --min-mib N --min-file-mib N --one-file-system --cross-mounts --no-statvfs --json
Exit codes: 0 analysis succeeded · 1 invalid arguments or unreadable target 
sys-disk-hogs . --top 15 --depth 2 --no-statvfs

sys-crash-triage

Post-Crash Forensics

Reconstructs unexpected reboots and hard resets via boot timelines, AMD FCH reset registers, NUL-byte log gaps, kernel panic/MCE/GPU signatures, and pstore/kdump readiness.

Key flags:
--boot N --boots-history N --tail-lines N --no-journalctl --journal-timeout SEC --show-steps --append-log PATH --exit-on-issue
Exit codes: 0 clean/report · 1 input/error · 3 unclean crash/fatal fault (with --exit-on-issue) 
sys-crash-triage --boot -1 --no-journalctl --show-steps

sys-net-watch

Network & Services

Tracks NIC RX/TX drops & FIFO/carrier errors, TCP retransmit ratios, socket state leaks (CLOSE_WAIT/TIME_WAIT), and per-CPU softnet_stat backlogs from /proc/net/*.

Key flags:
--interval SEC --samples N --iface LIST --top N --json --markdown --exit-on-issue --version
Exit codes: 0 healthy/report · 1 input/error · 3 non-healthy verdict (with --exit-on-issue) 
sys-net-watch --interval 1 --samples 2 --top 8

sys-systemd-watch

Network & Services

Monitors systemd cgroup v2 CPU/memory/I/O PSI throttling, rapid PID churn / crash loops, and journal file burst activity directly from /sys/fs/cgroup and /proc (zero systemctl calls).

Key flags:
--interval SEC --samples N --top N --unit PATTERN --cgroup-root PATH --json --markdown --exit-on-issue
Exit codes: 0 healthy/report · 1 input/error · 3 non-healthy verdict (with --exit-on-issue) 
sys-systemd-watch --interval 1 --samples 2 --top 10

Runnable Quickstart & systemd Timer Recipes

Copy-ready commands for verification, live stall triage, JSONL trend diffing, and background sampling.

1. Verify & Install Standalone Copies

Run the syntax, unit, and smoke checks, then copy all 7 self-contained tools into ~/.local/bin.

./scripts/verify.sh && ./scripts/install.sh

2. Live Stall Triage & JSONL Trend Diff

Capture stall-safe telemetry with --no-statvfs, append JSONL snapshots, and diff recent vs baseline windows.

sys-investigate --interval 2 --progress-check --no-statvfs --append-log ~/.local/state/sysadmin-tools/investigate.jsonl
sys-investigate --diff-log ~/.local/state/sysadmin-tools/investigate.jsonl --diff-window 5

3. Network & systemd Service Pressure

Check NIC drops, TCP retransmits, socket leaks, and cgroup v2 unit throttling without calling external tools.

sys-net-watch --interval 1 --samples 2 --exit-on-issue
sys-systemd-watch --interval 1 --samples 2 --top 10 --exit-on-issue

4. Serialize Heavy Disk Builds with sys-io-guard

Lock per backing block device from /proc/mounts, cap Cargo jobs, and lower child CPU priority.

sys-io-guard --path . --timeout 300 --cargo-jobs 4 --nice 10 -- bash scripts/verify.sh

5. Enable User systemd 5-Minute Sampler

Install the low-overhead oneshot unit from packaging/systemd/ (Nice=10, MemoryMax=128M, --no-statvfs).

mkdir -p ~/.config/systemd/user
cp packaging/systemd/sys-investigate-sampler.{service,timer} ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now sys-investigate-sampler.timer

6. Post-Crash & Memory/Disk Audit

Inspect unexpected reboots, OOM pressure, and reclaimable workspace caches with zero hung-mount blocking.

sys-crash-triage --boot -1 --no-journalctl --show-steps
sys-mem-watch --interval 2 --top 10
sys-disk-hogs . --top 15 --no-statvfs
